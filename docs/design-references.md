# Private Designreferenzen

## WaveOps

Drei privat bereitgestellte WaveOps-PDF-Dokumente dienen ausschließlich als
nicht öffentliche Designreferenzen. Für alle drei Dokumente gilt: all rights
reserved. Die PDF-Dateien werden weder im Repository noch in Quell-, Wheel- oder
anderen Distributionspaketen gebündelt.

U-Jagd übernimmt daraus keinen Text, keine Abbildungen, keine grafische
Gestaltung und keine Daten. Es gibt keine Transkription oder inhaltliche Kopie.
Die Referenzen lieferten nur abstrakte Inspiration für Arbeitsabläufe, etwa die
Trennung von Stationsaufgaben, den Wechsel zwischen Arbeitsansichten und die
schrittweise Auswertung unvollständiger Lageinformationen.

Die Nennung von WaveOps beschreibt ausschließlich diese private Referenznutzung.
Sie bedeutet keine Verbindung, Unterstützung, Billigung oder Empfehlung des
Projekts durch Autoren oder Rechteinhaber.
