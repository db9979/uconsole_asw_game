U-JAGD

TAKTISCHE U-BOOT-JAGD IN ECHTZEIT
by Dominik Bornhäußer

Jage U-Boote mit der Fregatte F-217 oder tauche selbst als U-Boot: Sonar, Radar, ESM, Hubschrauber und Torpedos an neun Stationen. Mit Remote Crew besetzen Freunde die Stationen im Browser.

uConsole / Linux

Gebaut für die ClockworkPi uConsole. Eine Zeile installiert das Spiel, danach hält es sich selbst aktuell:

curl -fsSL https://raw.githubusercontent.com/db9979/uconsole_asw_game/main/packaging/uconsole/install.sh | sh

Windows / Browser

U-Jagd-Windows.exe starten, fertig. Der PC wird zum Server, gespielt wird im Browser: als Crew mit je einer Station oder solo an allen. Updates kommen automatisch.
